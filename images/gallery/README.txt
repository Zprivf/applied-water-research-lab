DROP YOUR IMAGES AND GIFs HERE
==============================

Place your image and GIF files in this folder, then update
the src paths in content.js under the GALLERY section.

Supported formats: .jpg  .jpeg  .png  .gif  .webp

Recommended image size: 800×500 px (16:10 ratio works best)
GIF files work exactly the same as images — just set type: "gif"

Example entry in content.js:
  {
    src:     "images/gallery/my_photo.jpg",
    type:    "image",
    caption: "My Caption Here",
    desc:    "A short description of what this shows.",
  },
